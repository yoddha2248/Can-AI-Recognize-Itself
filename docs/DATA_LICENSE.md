# Data licence and third-party material

**Code** in this repository is under the MIT licence (`LICENSE`).

**Result files** under `results/` that we produced (numbers, logs, scores) are released under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), with one exception below.

**`results/transformer/b2_items.json.gz`** contains GPT-2 token IDs that encode 16-word
prompts taken from WikiText-103 (Merity, Xiong, Bradbury & Socher 2016, "Pointer Sentinel
Mixture Models", arXiv:1609.07843), together with continuations generated by GPT-2 Medium and
GPT-2 Large. WikiText-103 is distributed under
[CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/), so this file is distributed
under CC BY-SA 3.0, with attribution to the WikiText authors and to Wikipedia contributors.
The prompts are fetched from the Hugging Face dataset `Salesforce/wikitext`
(`wikitext-103-raw-v1`) when the scripts run.

**Models** are not shipped; scripts download them at run time from Hugging Face:
GPT-2 Small, Medium and Large and DistilGPT-2 (MIT licence; OpenAI, Hugging Face) and
GPT-Neo 125M and 1.3B (MIT licence; EleutherAI).

**Sanskrit texts** are not shipped. The paper cites them from GRETIL e-texts and their print
editions (see the paper's references).
